# 🌍 B2B Customer Scout

**从产品出发找对口企业**

根据产品规格、图片和目标市场找企业，核实匹配依据、公开联系人和拜访地点。

[↓ 下载 ZIP](https://github.com/RonnyMa-67/RonnyMa/releases/download/skills-2026-11-06/b2b-customer-scout.zip) · [SKILL.md](SKILL.md)

## 🧭 可以这样开始

附上产品、规格或参考图片，说明目标市场、客户类型和希望找到的数量，再让它找出匹配企业、联系人与证据。

## 📎 用之前看一眼

把下载的文件夹装进支持 Skills 的 AI 助手。技能本身不提供独立 AI 服务，也不会绕过宿主限制。查实时资料需要浏览能力；找到企业不等于确认采购意向，结果仍需核查。
