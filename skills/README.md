## 怎样看使用情况

- **文件下载次数**：GitHub 为每个 Release 附件累计记录 `download_count`，可在[发布 API](https://api.github.com/repos/RonnyMa-67/RonnyMa/releases/tags/skills-2026-11-06)的 `assets` 中查看。按附件的 `name` 区分三个技能；跨版本时汇总对应附件。
- **实际使用反馈**：查看[使用反馈 Issues](https://github.com/RonnyMa-67/RonnyMa/issues?q=is%3Aissue%20%22%5B%E4%BD%BF%E7%94%A8%E5%8F%8D%E9%A6%88%5D%22)，结合技能、场景和任务结果判断；“尚未使用”的反馈不计为实际使用。
- **访问和克隆**：仓库管理员可查看 [Traffic](https://github.com/RonnyMa-67/RonnyMa/graphs/traffic)。需要长期趋势时自行定期保存短期窗口数据。

下载次数包含重复下载、维护者验证或自动工具获取，不能等同于独立用户数；复制源码、旧 ZIP 直链和整仓下载不计入 Release 附件下载量。历史下载不能补计。反馈提交是公开且自愿的，不自动收集或回传客户资料与任务内容。
