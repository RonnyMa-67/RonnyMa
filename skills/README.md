## 🚀 拿来怎么用

下载对应 ZIP，解压后保留文件夹结构，在支持 Skills 的 AI 助手中安装。没有安装入口时，也可以将 SKILL.md 作为说明使用。实时研究需要宿主具备浏览能力，表格导出需要文件工具或可选脚本。

## 🫧 有人下载，也有人用过

GitHub 在 `assets[].download_count` 中累计每个 Release 附件的下载次数。重复下载、维护验证、自动工具获取都会算进去，所以它不等于用户人数。源码复制、整仓下载与旧 ZIP 直链不计入；历史下载无法补计。
