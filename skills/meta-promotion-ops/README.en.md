# 📣 Meta Promotion Ops

**Connect promotion with follow-up**

Organize Facebook / Instagram objectives, creative, audiences, budgets, forms, messages, and operational handoffs.

[↓ Download ZIP](https://github.com/RonnyMa-67/RonnyMa/releases/download/skills-2026-11-06/meta-promotion-ops.zip) · [SKILL.md](SKILL.md)

## 🧭 Give it a starting point

Describe the brand, real product, objective, market, budget, schedule, and response channel. Ask for a promotion plan. If account operations are needed, specify the permitted changes and publishing scope.

## 📎 Before you start

Install the downloaded folder in a Skills-compatible AI host. This package does not provide its own AI service or bypass the host’s limits. Current research needs browsing. Evidence still needs review; a company match does not prove buying intent.

Campaign actions require authorization for the actual account and task. Saving a draft, submitting changes, review, scheduling, and live delivery are different states. Never treat a plan as evidence that an ad is running.
