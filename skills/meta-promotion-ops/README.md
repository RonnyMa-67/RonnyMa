# 📣 Meta Promotion Ops

**把推广和后续承接串起来**

整理 Facebook / Instagram 的目标、素材、受众、预算、表单、消息与执行交接。

[↓ 下载 ZIP](https://github.com/RonnyMa-67/RonnyMa/releases/download/skills-2026-11-06/meta-promotion-ops.zip) · [SKILL.md](SKILL.md)

## 🧭 可以这样开始

说明品牌、真实产品、目标、市场、预算、时间和承接方式，再让它整理推广方案。需要操作账户时，把允许修改和发布的范围说清楚。

## 📎 用之前看一眼

把下载的文件夹装进支持 Skills 的 AI 助手。技能本身不提供独立 AI 服务，也不会绕过宿主限制。查实时资料需要浏览能力；找到企业不等于确认采购意向，结果仍需核查。

广告操作需要具体账户与任务的授权。草稿保存、提交、审核、排期和投放是不同状态，方案写完不代表广告已经上线。
