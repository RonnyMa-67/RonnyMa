## 🚀 Install

Download the matching ZIP, extract it, and keep its folder structure when installing in a Skills-compatible AI host. A standalone SKILL.md can also be used as instructions where no installer exists. Live research requires host browsing; spreadsheet output requires host file tools or the optional utilities.

## 🫧 Downloads and real use

GitHub counts each Release attachment download in `assets[].download_count`. Repeated downloads, maintenance checks, and automated fetches are included; this is not a user count. Source copies and old direct ZIP links are not counted. Historical downloads cannot be recovered.

[Release download counters](https://api.github.com/repos/RonnyMa-67/RonnyMa/releases/tags/skills-2026-11-06) · [Share usage feedback](https://github.com/RonnyMa-67/RonnyMa/issues/new?template=skill-usage.yml)

Feedback is public and optional. Nothing in these Skills automatically submits feedback or sends task data. Keep customer information, account details, and internal files private.
