# 产品口径文件模板（product-context）

每个品牌建一份，放在工作区里长期维护。**写任何广告文案、主页文案、自动回复之前先对一遍这份文件。** 它是所有对外文字的单一事实来源：定位、说法、承诺边界都以它为准，它更新了，所有新文案自动跟着对。

## 为什么先建它：一个真实教训

实战中踩过的坑：把「速溶饮料机」写成「咖啡机」投了出去。问题是这台机器根本不只是做咖啡——它是针对目标市场优化过的速溶饮料机：转速调校过、主打小杯量、所有速溶粉都能用，咖啡粉只是其中一种。一个词说窄了，广告吸引来的人群、客户的预期、销售的接话方式全跟着错位，而且广告、帖子、自动回复如果是各写各的，这个错误会在四个地方同时出现。

教训：**口径不是文案问题，是源头问题。** 每次写文案前先花两分钟对口径，比事后逐条纠正便宜得多。

---

## 模板（复制后填空）

```markdown
# {{COMPANY}} 产品口径文件（写任何文案/广告前先对一遍）

定版：{{DATE}}。来源：所有者的历次纠正与确认。

## 产品定位（最重要的一条）

- {{核心品类的一句话定位：它到底是什么、为哪个市场/场景优化、和相近品类的区别}}
  英文说法：{{official English phrasing}}
- 全线产品：{{产品线清单}}
- 客户是谁：{{目标客户类型，如进口商、经销商、酒店/餐厅/咖啡店运营者}}
  明确不是目标客户的：{{如个人消费者}}

## 禁用与红线

- 绝不承诺：价格、MOQ、交期、运费（一律引导到人工/表单细聊）。
- 不写没核实过的认证、独家代理、销量数字。
- {{品类特有红线，如：不把 A 品类写成只能做 B；不把商用设备说成家用小家电}}
- 展会信息（如在展期）：{{展会名、展馆、展位 {{BOOTH}}、日期、团队在当地待到哪天}}

## 常用事实

- 公司：{{COMPANY}}（{{公司全称}}），官网 {{WEBSITE}}，IG {{IG_HANDLE}}。
- 工作时间：{{BUSINESS_HOURS}}。
- OEM/ODM 口径：{{如「可谈，细节人工确认」}}。
- 回复承诺口径：{{如「一个工作日内回复」——感谢页、自动回复、表单里统一，不承诺做不到的时限}}。

## 文案定式

- 结构：第一句点名买家或场景 → 2–3 句卖点 → 行动号召（私信我们 / 填表单）→ 标签 ≤5 个。
- 语言：英文为主；字幕烧进视频（英文，有外语版时只用人工审核过的版本）。
- 视频：1 秒内机器动起来，一条只讲一类机器/一个卖点，14–30 秒为主。
```

## 维护规则

- 所有者每纠正一次口径，当天就更新这份文件并改定版日期——口头纠正不落文件，等于没纠正。
- 新文案与口径文件冲突时，以口径文件为准；觉得文件过时了，先改文件、再写文案，顺序不能反。
- 展会信息、主推机型这类时效内容，过期立刻删或更新，避免旧展位号、旧日期被套进新文案。
