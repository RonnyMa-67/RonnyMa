# 便当盒数据卡规格（广告汇报格式）

所有广告汇报统一用这个格式：聊天里发一张便当盒式数据卡（大小格子拼贴的 HTML 卡片），同时附一行文字版结论作兜底。核心要求就两个字：**简单**——结论 + 关键数字，不堆明细。

## 结构

```
📊 {系列名} · {时段}数据卡片（{日期}）
结论：{线索数} 条线索 / ${花费} / 单条 ${CPL} {✅ 成本健康 | ⚠️ 偏高 | 🔴 异常}

💰 花费 ${花费} {进度条 ▓░}（日预算 ${预算}，已用 {%}）
🎯 线索 {n} 条 · 单条 ${CPL}
👀 展示 {impressions} · 点击 {clicks} · CTR {%}

分广告组：
{🟢投放中|⏸已暂停|⏳待开始} {组名} — ${花费} · 线索 {n} · ${CPL}/条
（每组一行）

状态：{账户/投放一句话}
```

- **结论行永远在第一位**，一句话说清四件事：线索数、花费、单条成本、健康判断。
- 卡片排版：大格 = 结论（主角数字），中格 = 花费 / 每条线索成本，小格 = 其他指标与各广告组状态，最后一格 = 状态行。
- 指标格把关键 KPI 合并进一个整格排列：展示 / 点击 / 点击率 / 每次点击成本 / 千次展示成本 / 点击后留资率（全部由实测数算出，不单独编）。
- 「接下来还要投」这类前瞻数字 = 剩余天数 × 各自每天预算，写清算法口径。

## 健康阈值

以 B2B 设备表单线索为默认（**可按业务调整**，调整后全周期统一口径）：

| 单条线索成本 | 标记 |
|---|---|
| ≤ $10 | ✅ 成本健康 |
| $10–20 | ⚠️ 偏高 |
| > $20，或有拒登 / 账户异常 | 🔴 异常 |

状态符号：🟢 投放中 / ⏸ 已暂停 / ⏳ 待开始。

## 设计规范（定版：撞色只做点缀）

- **撞色克制**：只有大格（紫色渐变）和收尾格（柠檬绿）用饱和色，累计数字用亮橙色点一下；其余格子一律中性底（跟随主题的卡片底色 + 细边框）、深色字。全格撞色会被评为「杂乱」，不要做。
- **排版整齐**：网格只用整齐的跨度（大格整行、双格对开、指标合并成整格），间距 10px、内边距 16px、圆角 16px 全卡统一；**格子总数 ≤ 8**。
- 进度条只用于「花费 vs 预算」这类有分母的量：10 格，▓ 为已用，░ 为剩余。

## 三个周期各自的主角格

- **早报（投放期每天约 08:40）**：主角格是「**昨天新增 N 条线索 · 等你分配**」，赶在所有者早上分配线索之前到；再带昨日花费/每条成本、累计总数（橙色）、还剩几天。投放期外自动不发。
- **周报（周一早上）**：在日报基础上加一格上周汇总（上周花费 / 线索 / 平均成本）。
- **月报（次月 2 号早上）**：上月整月汇总（总花费 / 总线索 / 平均成本 / 表现最好的一条广告），供所有者写月报取数。

## 规则与红线

- 数字只用接口实测值并注明时段；**「不可用」不写成 0**，接口没给的指标直接不出现或注明缺失。
- 最后一行只报状态（正常 / 具体异常），不展开分析；需要解读时另起一段说。
- **需要所有者操作或决定的事项，加粗并单列**，不埋在正文里。
- **用词大白话红线**：不用企业黑话和平台黑话——不说「战报」，不说「赋能拉满」这类词；标题和标签都用日常说法，如「迪拜展会广告」「每条线索成本」「账户正常」。
