# AIDEWO 国际站主图 · Muse / Gemini

[打开主图版式和复制指令](https://ronnyma-67.github.io/RonnyMa/tools/aidewo-images/?mode=main)

## 使用方法

1. 备好当前型号透明机身 PNG、原始 Logo、结构实拍，以及核对过的英文和参数。参考图用于灯光、构图和留白。设备、屏显和出杯口以本款实拍为准。
2. 逐页选版式并填入自己的场景描述。点击复制 Muse 或 Gemini 指令，粘贴到对应产品。先生成一张没有设备、品牌、字和数字的背景。出现虚构机器或背景遮挡位置时只改背景。
3. 把背景、原机 PNG 和 Logo 放进网页，输入已经核实的文字。只有原图带背景时也可直接上传实拍，背景保持空白。核对后导出独立 PNG。六张都是 1200 × 1200 px。
4. 按序检查原机轮廓、面贴、屏幕、拉杆、出液口和接水盘。把整套缩到约 200 px 宽，检查品类、型号和关键数字是否明显。技参、净毛重、箱规和适用电源以本型号为准。缺项时删对应声明或改为询价项。

| 次序 | 买家要看什么 | 优先素材和保留文案 |
|---|---|---|
| 1 | 这是什么设备 | 完整实机、品类标题、小号型号、一个最强参数 |
| 2 | 能做多少、提供几种选择 | 容量或确认产能，配对应成品杯或实拍 |
| 3 | 怎么操作 | 本款拉杆、触屏或出杯口的实拍，配一行操作 |
| 4 | 有什么结构优势 | 真实结构特写和已确认材质，避开推测的内部结构 |
| 5 | 怎么发货 | 包装实拍和已确认箱规、净重和毛重 |
| 6 | 能装得下吗 | 整机尺寸及对应电压、功率和频率 |

视觉基准为中性白、AIDEWO 深蓝和少量品牌绿。让机器占主体，避免斜切、亮光边框和装饰短线。Logo、数字和英文由版式合成，背景由 Muse 或 Gemini 提供。设备始终等比缩放。按上架顺序逐张保存。

## 快速例子

主图第 1 张选 ADW15LX2，标题 `Commercial Slush Machine`，关键数字 `2 × 15 L`，说明 `Independent bowl controls`。场景使用真实商用柜台，保留放机器的空间，两种冰沙在一侧提示口味。数字是容量，不能替代持续产能。

Gemini 支持在图片编辑里上传参考图。Muse 版本能附参考图时，可把参考图仅用于空间和光线。两个平台都可运行纯文本场景指令；场景质感仍受模型及版本影响。
