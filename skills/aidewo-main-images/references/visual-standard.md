# 六张轮播与视觉规范

[GLT4-04 定稿参考](../assets/glt4-04-gallery-reference.jpg) 按左到右、从上到下排列。用作取景、信息层级和品牌一致性的视觉基准。新机型使用自己的原始照片和真实卖点。旧参考机型、面贴、饮品和参数仅用于说明这套风格。

| 顺序 | 买家要判断什么 | 取景与信息 |
|---|---|---|
| 1 首图 | 是什么，为什么值得点进去 | 完整机器占画面视觉主位，优先用三分之四视角。保留适度的真实营业场景和一个出品示例，产品标题最醒目。核心卖点给一个醒目的数字或同等视觉层级，最多三项短辅助卖点。 |
| 2 出品或菜单 | 门店可以买来卖什么 | 用一到两种代表性出品并排，或用对应场景说明用途。饮品可以靠前，设备退到侧后方。仅展示确认支持的出品。 |
| 3 操作或效率 | 店员如何用，高峰怎么出品 | 用原始面板、控制区或出液区两个特写和简短流程箭头。使用最新确认的效率数据。 |
| 4 容量或备料 | 如何补料，能放多少 | 用开门内舱、料盒或料桶的实机素材。用简洁图示标清数量、容量或对应部位。结构看不清时改用已核实的补料特写或另一个运维判断点。 |
| 5 出品质量 | 出品表现能不能满足我的菜单 | 以成品近景、真实质感或已确认的对照示意为主，配一个对应的温度、质感、份量或保鲜指标。设备可退到景深。 |
| 6 摆放与用电 | 放得下、接得上吗 | 用较宽的真实台面场景表现体量，紧凑展示已确认的尺寸和电气规格。未核实轴向时仅列原尺寸顺序。 |

## 视觉

- 1:1 手机优先，约 5–7% 安全边距。左上 AIDEWO 原 Logo 等比放置，型号使用小号淡冰蓝细框胶囊。主标题保持深蓝重字，一处品类关键词可用 AIDEWO 亮蓝（参考 #0759B5）。型号和 Logo 让位于标题。
- 大面积干净白或浅色，AIDEWO 深蓝负责阅读，浅蓝负责过渡，品牌绿用于少量强调。右下可保留贴边细弧，幅度克制；空间不足可省略。
- 背景按品类选真实商用场景。冷饮可用浅色石英、长虹玻璃和冷光，咖啡或速溶可用自然暖光，设备色彩与品牌色保持一致。整套用同一视觉语言，取景和视觉主角按每张任务切换。
- 每张一个主标题和一个主判断点。以产品、饮品特写、精简示意、数字和少量线性图标表达。少用装饰，避免工厂弧形大底、飘浮装饰、重复图标、过度反光和各页同一构图。
- 原机几何、机身比例、外壳、屏幕、按键、通风口、出液口、托盘和内舱保真。可改善清晰度、反光、白平衡和材质层次，但避免重画硬件和菜单细字。授权的新面贴需贴合实际边界，保持接口、散热孔和屏幕位置真实。未量产面贴应注明效果预览。
- 交付前缩到约 200 像素宽检查。首图能认出产品和类别，技术图能读主数据。检查 1:1、品牌标识、型号、英文、参数单位、原机细节、贴画版本和六张顺序。
