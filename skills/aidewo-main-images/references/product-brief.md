# 新机型资料模板

有资料就直接填；资料已经在对话内时直接提取，无需让用户重复填写。

| 字段 | 填写内容 |
|---|---|
| 型号 / 英文品名 |  |
| 目标市场、采购人和使用场景 | 经销商、餐饮连锁、便利店等 |
| 确认的主卖点 | 一项，附对应数据或可展示的功能 |
| 其余已确认卖点及参数 | 出杯速度、料盒容量、温度、尺寸、电压、功率等，适用才写 |
| 支持的饮品或操作流程 | 用实际支持的选项和步骤 |
| 原机素材 | 整机三分之四、正面、屏幕/面板、出液区、开门、场景，按现有素材填写 |
| 面贴状态 | 原面贴、已定稿面贴，或明确授权设计概念 |
| 上图语言与附加需求 | 英文默认，可填写小语种或只改某张 |

以最新明确确认的值为准。资料冲突则只追问会影响成图的一点，其余可先做。缺少证据的规格、认证、承诺和可定制项目不要上图。缺图时用已有的真实视角或改用已证实的判断点，不能补造硬件。参照样例的 10 杯/分钟仅属于 GLT4-04。

调用示例：用 @aidewo-main-images，按 GLT4-04 定稿标准做这个机型的 6 张国际站主图，产品原图和参数在附件。
