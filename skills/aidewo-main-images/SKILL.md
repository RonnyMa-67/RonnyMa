# AIDEWO 国际站主图

1. 从当前对话、用户选中的原图、最新确认的资料提取产品事实，缺项按 [product-brief.md](references/product-brief.md) 处理。读 [visual-standard.md](references/visual-standard.md) 和其中的定稿参考图再构图。
2. 默认交付六张独立 1:1 主图，按买家判断顺序排。用户只点名某张时，只改对应图片。用户指定继续沿用某版时，以明确选择的那版为编辑底图。
3. 先确定唯一首图核心卖点，再逐张分配不同判断点和取景。用经过核实的可视化帮助买家看懂机型、出品、操作、内部结构和摆放。不同品类替换具体内容，保留决策顺序。
4. 用用户提供的原机照片做产品底图。按需使用当前可用的图像编辑能力处理场景、光影和版式，优先锁住机器区域合成。仅在用户授权后改印刷面贴。核对屏幕、通风口、出液口、内舱和机身比例。发现被重绘或变形时，先使用原素材修正再交付，无法还原时明确标为预览并指出差异。
5. 按参考规范逐张检查标题、型号、数据、实物结构和手机缩略图。交付独立图片并注明上架顺序。用户明确要求的变更和最新确认的参数优先，不用旧图覆盖。

生成图默认用英文上图。用户明确指定目标语言时按目标市场本地化。只做国际站主图。
