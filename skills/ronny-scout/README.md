# 🔎 Ronny Scout

**把已有询盘研究明白**

保留原始需求，核实公司背景、官网、社媒和公开联系人，再整理合作潜力、优先级与下一步。

一条询盘，后面总还有一串问题。这个 Skill 从原始需求查起，把事实、推断和未知分开，再放进固定十列的研究表。希望表格里能少一点万能的「建议进一步沟通」🫠

## 🧭 可以这样开始

附上询盘或客户表，请用 Ronny Scout 研究这些线索，保留原始需求，核实公开资料，输出 A–J 客户研究表。

## 📎 用之前看一眼

把下载的文件夹装进支持 Skills 的 AI 助手。技能本身不提供独立 AI 服务，也不会绕过宿主限制。查实时资料需要浏览能力；找到企业不等于确认采购意向，结果仍需核查。

## 🛠️ 可选表格工具

原有安装说明、MIT 许可、A–J 字段、脚本命令和测试方法保留在[英文技术指南](GUIDE.en.md)。脚本负责整理已经研究过的数据，不会自己执行网页背调。
